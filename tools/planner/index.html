Turn a task tracker into a daily plan you actually follow.

MyPlanner is a Google Apps Script tool that reads a lightweight tracker sheet + today’s calendar, then writes a structured plan into Google Docs — prioritized, time-blocked, and resilient to “day drift.”

Purpose

Most task trackers fail at the moment of execution: the day starts, meetings happen, energy shifts — and the list becomes noise. MyPlanner exists to convert a tracker into a decision-ready morning plan: what matters today, when it happens, and what to say when you need to move work forward.

Less drift A tight “Today’s Focus” prevents reactive work from eating the day.
Fewer open loops Draft messages + targets reduce the friction of follow-ups and handoffs.
Execution-ready Time blocks with buffers assume real life (20% overrun) so plans survive contact.

What breaks without this

  • Task lists grow, but priorities stay implicit — everything feels “urgent.”
  • Follow-ups happen late because the “next step” isn’t surfaced at the start of the day.
  • Calendar reality and task reality are disconnected (meetings steal the execution window).
  • You spend peak-energy time deciding what to do instead of doing it.
  • Plans don’t compound because the system never captures “Where we left off.”

What it does

  • Reads a tracker sheet (first tab) and keeps active/recent items (e.g., active statuses or recent touches).
  • Reads today’s calendar and turns it into a realistic block schedule.
  • Generates a structured plan with consistent headers (Focus → Top 5 → Schedule → Draft messages → Targets).
  • Writes the day’s plan into a running Google Doc (upsert by date so re-runs replace today cleanly).
  • Normalizes formatting (H2/H3 + base font) so the doc stays readable over time.

If an OpenAI key isn’t present, MyPlanner still produces a deterministic fallback plan — so the workflow never blocks.

How it works

  • Inputs: Google Sheet (task tracker), Google Calendar (today), Script Properties (optional OPENAI_KEY).
  • Planner engine: prompt builder + robust section parser (so headers don’t drift).
  • Output: Google Doc “My Planner — Control Panel” with one H2 section per day.
  • Controls: custom Sheets menu (“Run Daily Plan now”, “Reset doc & write today”).
Privacy-first default: the tool runs in your Google environment. If you enable the LLM call, only the summarized tracker bullets + today’s calendar bullets are sent to the model.

Where it fits

  • Downstream of work signals: tasks, priorities, last-touch dates, and calendar commitments.
  • Upstream of execution: outreach, writing, building, follow-ups, and closing loops.
  • Feeds other agents: planning output can become inputs for routing, audits, or portfolio ops.
